RAID Companion Reader Preview 0.2.0

This is an installable connection-test preview for Windows 10/11 x64.
Python is included. You do not need to install Python or create a login.

It detects RAID through Plarium Play and tests read-only memory access.
Inspect memory samples can read up to 24 experimental champion records
on the specifically supported game build. These may include stale or
non-player records. They are not a verified active account roster.
Read roster candidates reads whole, stable champion dictionaries, including
storage flags. Names can be unavailable when description caches are empty.
Read gear candidates reads basic artifact records from stable containers.
Account identity, final stats, equipped links and bonus stats remain
unverified. Nothing is imported into the web companion automatically.
No champion or artifact sync, equipping, selling, or battles are implemented.

Open RAID, then choose Check RAID connection. If Windows denies access,
close the reader and right-click its shortcut, Run as administrator.
Windows will ask for permission. No security protections are disabled.

The web companion opens separately in your browser. Existing browser
sessions and notes stay in that browser; no new login is added here.
Diagnostics stay local unless you choose to share a saved report.
Sample reports can include champion names, IDs, ranks and levels.

This preview is unsigned. Uninstall it through Windows Settings > Apps.
Installing this preview is not completion of the full Xtender-style reader.

PC replay preview: the installed battle-runner folder contains a separate CLI. It defaults to observing without clicks. Live replay requires explicit calibration and the --live-replay switch. Read REPLAY-PREVIEW.md. Live game behavior has not been validated by this build. iPadOS remains a separate web planning target.
