# Champion portraits

Public catalog: https://rsl-x.vercel.app/tools/champions-index

Downloaded portraits use normalized champion-name filenames. Existing supplied art is preserved. Mythical alternate forms share the base portrait. Game artwork belongs to Plarium; this is an unofficial fan companion. Run `scripts/sync-portraits.py` to refresh the catalog. The manifest records catalog coverage and download failures; it does not claim coverage of champions absent from the source.

RaidWiki supplemental catalog: https://raidwiki.com/champions (458 entries checked; five additional filenames downloaded).
